# Hosting status

Use deploy/README.md for current configuration and docs/OPERATIONS.md for release
and incident procedures. Frontend and Python worker run separately; all speech is
not on-device. LiveKit and Groq are external services and Kokoro runs on worker CPU.

No hosting account, uptime guarantee, payment plan, production URL, alert recipient,
or region has been provisioned by these local repairs. Free or sleeping development
compute is suitable for demos, not proof of always-on service. Measure the intended
hardware and provider allocation before selecting capacity or making latency claims.
